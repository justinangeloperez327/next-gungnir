# Next Gungnir\n\nThe documentation website for the Gungnir Framework.\n\nThe site is built with Next.js and presents Gungnir as a C++23 web framework and source-language toolchain. Framework documentation is based on the behavior and public contracts maintained in the main `gungnir` repository.\n\n## Development\n\nRequirements:\n\n- Node.js 20.9 or newer\n- npm\n\nInstall dependencies and start the development server:\n\n```bash\nnpm install\nnpm run dev\n```\n\nOpen `http://localhost:3000`.\n\n## Routes\n\n- `/` — framework landing page\n- `/docs` — framework documentation\n\n## Quality checks\n\n```bash\nnpm run lint\nnpm run typecheck\nnpm run build\n```\n\n## Stack\n\n- Next.js 16\n- React 19\n- TypeScript\n- Tailwind CSS 4\n- ESLint\n\n## CI/CD\n\nGitHub Actions runs linting, type checking, and a production build for pushes and pull requests. Production deployment from `main` can use Vercel when the required repository secrets are configured.\n
